## 项目概况

- **技术栈**：Qt 6.11 + QML（FluentUI 组件库）+ libmpv（D3D11 硬解渲染）
- **平台**：Windows 为主；macOS / Linux 提供 GitHub Actions 构建脚本（手动触发）
- **已实现**：视频/番剧播放（多清晰度、音质选择、字幕）、直播播放与弹幕、评论与图片浏览、动态、搜索、用户空间、历史记录等
- **数据来源**：全部来自哔哩哔哩官方 Web / APP 接口，需使用者自行登录

## 自定义弹幕字体

弹幕字体可以从外部加载，不需要改代码或重新编译。

**做法**：在客户端目录（`BbQ.exe` 所在目录）下新建一个 `fonts` 文件夹，把字体文件放进去，重启客户端即可生效。

```
BbQ.exe
fonts/
  ├─ YourFont.ttf
  ├─ AnotherFont.otf
  └─ SomeCollection.ttc
```

支持 `.ttf` / `.otf` / `.ttc` 三种格式。几点说明：

- **只影响弹幕**，界面字体不随之改变；找不到可用字体时回落到系统默认字体。
- **可放多个**，按文件名排序进回退链，排在前面的优先（例如 `01-Alpha.ttf` 优先于 `02-Beta.ttf`）。
- 只扫描 `fonts` 目录本身，**不递归子目录**，字体文件请直接放在这一层。
- 扫描发生在启动时，**新增或替换字体后需重启客户端**；加载失败的单个文件会被跳过，不影响其它字体。
- Linux 下路径为 `~/.config/BbQ/fonts/`；若该目录不存在而程序目录下有 `fonts`，会回退读取程序目录（兼容早期绿色版）。
- 请自行确认所用字体的授权允许你的使用方式，本项目不附带任何字体文件。
