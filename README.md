## 项目概况

- **技术栈**：Qt 6.11 + QML（FluentUI 组件库）+ libmpv（D3D11 硬解渲染）
- **平台**：Windows 为主；macOS / Linux 提供 GitHub Actions 构建脚本（手动触发）
- **已实现**：视频/番剧播放（多清晰度、音质选择、字幕）、直播播放与弹幕、评论与图片浏览、动态、搜索、用户空间、历史记录等
- **数据来源**：全部来自哔哩哔哩官方 Web / APP 接口，需使用者自行登录

## 构建

```bash
# 依赖：Qt 6.11.x（含 Qt Quick / ShaderTools）、CMake 3.16+、MinGW 或 MSVC
# FluentUI 需先自行编译并安装到 Qt 的 qml 目录
cmake -B build -DCMAKE_PREFIX_PATH=<Qt 路径>
cmake --build build --config Release
```

`third_party/mpv-dev` 已内置 libmpv 头文件、导入库与运行时依赖，无需额外下载。
